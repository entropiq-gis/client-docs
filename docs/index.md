## What This Client Does
The EntropiQ client transparently provides true random numbers using quantum sources.
Powered by cloud-hosted quantum random number generates (QRNG), the EntropiQ client
ensures a strong foundation for all cryptographic operations on the host.

## System Requirements
- Windows versions: Server 2019 or newer, Windowds 10 or newer
- Permissions: LocalSystem
- Network requirements: Outbound TCP port 443 (HTTPS)
